### Rules & Guidelines (STRICTLY ENFORCED)

1. **Feedback-First Priority (CRITICAL)**: Both types of reviewer feedback are your primary directives.
   - For every item listed in the **Script Reviewer Feedback**, you MUST apply the provided correction directly to the corresponding clip or character entry.
   - For every item listed in the **Storyboard Reviewer Feedback**, you MUST identify the root cause in the script (e.g., ambiguous spatial description, missing detail, incorrect character action) and revise the script to eliminate that ambiguity or error.
   - Any clip or character entry NOT referenced in either feedback must be preserved exactly as-is.
2. **Visual Source of Truth (CRITICAL)**: The manga images remain the ultimate source of truth. If the existing script or character descriptions contradict the visual details, follow the manga visuals in your corrected output.
3. **Screen-Space Spatial Descriptions**: All spatial descriptions (e.g., left, right, front, back, near, far) MUST be explicitly defined from the camera's perspective. Always use phrasing such as "from the camera's perspective", "on the left side of the screen", or "facing screen right". Detail characters' body orientations clearly.
4. **Absolute Clip Correspondence**: The previously generated script already maintains a one-to-one correspondence between clips and panel images. You MUST preserve this correspondence exactly. Do not merge, split, add, or reorder any clips.
5. **Scene Configuration & Object Quantities (CRITICAL)**: Within each clip, you MUST meticulously describe the layout of the entire scene. Explicitly count and state the exact quantity of visible objects, and describe their left/right spatial relationships to one another (e.g., "Three boxes are stacked on the left side of the screen, with a desk to their right"). Exception: this "describe everything" requirement does NOT extend to speech bubbles, dialogue boxes, or sound-effect/SFX lettering — those are excluded entirely, see Rule 9, no matter how large or visually prominent they are in the panel.
6. **Silent Panels**: If a panel image shows a character reacting without any speech bubbles, DO NOT assign any dialogue to that clip. Describe it purely as a visual and silent moment.
7. **Cinematic Descriptions**: Use terms like "Medium shot", "Extreme close-up", "Low angle". Accurately represent the composition and intent of each panel.
8. **Accessory & Small Object Rule**: Any small objects or accessories (e.g., bags, phones, glasses, jewelry, handheld items) MUST be described within the corresponding clip's scene description, including their quantity and spatial placement. DO NOT include these items in the character description fields.
9. **No Written Text Inside "environment"/"description" (CRITICAL — this bans a CONCEPT, not a word list)**: Do not describe speech bubbles, dialogue boxes, or sound-effect/SFX lettering inside a clip's "environment" or "description". This covers the graphic itself, the words it contains, AND any paraphrase of it — "sound effect", "onomatopoeia", "katakana/kanji", but also "graphical letter-like strokes", "stylized writing-like marks", "text-shaped bursts", or any other wording that describes the same thing without naming it directly. The test is substance, not vocabulary: if what you are describing is, in substance, text/lettering/writing/symbols drawn on the panel, omit it entirely — do not try to describe its shape or form using different words to get around this rule. When a panel's background includes SFX lettering, describe only the OTHER background elements (radiating lines, impact bursts, lighting, colors, etc.) and simply don't mention the lettering at all. Describe the underlying action, pose, and expression instead (e.g. a roaring creature: describe the open jaw and bared teeth, not the sound-effect text next to it). All actual dialogue/thought text goes in the "dialogue" field instead (see Rule 10).
10. **Dialogue Field (additive field, separate from description)**: Put every line of spoken or thought text for this panel into the "dialogue" array, one object per line, in reading order, each with "speaker" (the Character[id] integer, or null if off-screen/unidentifiable), "type" ("dialogue" or "thought"), and "text" (the exact line, no surrounding quote marks needed). Use an empty array [] if this panel has no speech/thought bubble. ONLY include lines that correspond to a speech/thought bubble physically present in this specific panel. If the Storyboard/Script Reviewer Feedback references dialogue accuracy, apply the correction here, not inside "description".
11. **Characters In Panel (CRITICAL, additive field)**: In each clip's "characters_in_panel" field, list every integer Character[id] that appears anywhere in that clip's "description" field above, as a JSON array of integers in ascending order (e.g. [1, 2]). Use an empty array [] if no character is referenced in this clip's description. Do NOT invent ids that are not present in the "characters" array.
